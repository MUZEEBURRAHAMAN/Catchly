Catchly Product
Design System

A high-precision design system crafted specifically for Catchly's local-first Chrome extension and marketing surfaces. Built around calm clarity, tabular financial scanning, and privacy by architecture.

Privacy by Architecture

No telemetry, no tracking pixels. The interface communicates safety and trustworthiness through transparent local storage.

Tabular Numerics

All prices, currencies, countdowns, and renewal dates use JetBrains Mono tabular figures to eliminate visual jitter during sort.

Urgency with Restraint

Color is functional. Crimson, amber, and green are reserved exclusively for billing urgency, keeping the workspace calm.

Compact Density

Engineered for the 380px extension popup, 420px side panel, and responsive web screens with a strict 4px grid.

10 · Guidelines

Implementation Rules (Do & Don't)

✓ DO

  • Use font-variant-numeric: tabular-nums on all prices, dates, and countdown numbers.
  • Keep crimson (--ds-danger) strictly for urgent renewals (≤ 2 days) and expiring free trials.
  • Isolate all in-page content script toast DOM elements inside an open Shadow Root to avoid CSS bleed.
  • Use the 4px spacing scale for all padding, margins, and gaps.
  • Support Dark, Light, and System modes seamlessly across the popup and options page.

✗ DON'T

  • Never transmit subscription names, amounts, or billing credentials to any external server.
  • Don't use decorative drop shadows in dark mode — use the surface elevation ladder instead.
  • Don't invent ad-hoc hex colors outside the defined design system tokens.
  • Never use proportional font numbers for lists of prices to prevent layout shifting.
  • Don't add intrusive animations that exceed 280ms duration.
